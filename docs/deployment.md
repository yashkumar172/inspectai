# Deployment

Deployment (SPEC.md Section 15) is optional. The app is deployed on Streamlit Community Cloud from the hosted bundle below, and was tested manually on the live app with normal and defective images; the link opens publicly without signing in. Other browsers and screen sizes, and the host's memory use and reliability under load, have **not** been tested. The primary supported mode is local: `streamlit run app.py` on the machine that holds the artifacts. The project supports **Python 3.12 only** (`requires-python = ">=3.12,<3.13"`; `.python-version` pins `3.12` for uv and pyenv). Streamlit Community Cloud chooses its Python version in the app's **Advanced settings** at deploy time (its default is newer than 3.12), so select 3.12 there; reboot or redeploy the app after changing it.

## Hosted run without the dataset

Neither the dataset nor a pretrained-weights cache is available on a host, so a hosted copy (for example on Streamlit Community Cloud) runs from a precomputed bundle in the `hosted/` folder (about 413 MB, built from real results by `python scripts/export_hosted_bundle.py --force`; `--models classical` builds the small Model A-only bundle). When `INSPECTAI_DATA_ROOT` is not set, the app uses `hosted/artifacts` and `hosted/reports` automatically and points `TORCH_HOME` at `hosted/torch_cache` (unless `TORCH_HOME` is already set); if `INSPECTAI_ARTIFACT_DIR` or `INSPECTAI_REPORT_DIR` is set, that one is used instead. **Model C (PatchCore-inspired, `dev` profile) is the default inspection model**; Model A stays selectable. `requirements.txt` installs the project with the CPU PyTorch wheels. The bundle contains:

| Included | Not included |
|---|---|
| `summary.json` and `predictions.csv` of every evaluated run, the comparison tables, and one comparison figure per category (the evaluation dashboard) | The dataset and its test images (the "choose a test image" option is hidden) |
| Model C `dev` artifacts for all seven categories (about 46 MB each, mostly the coreset memory bank) and the ResNet-18 ImageNet weights they were fitted with (44.7 MB, shared; hash-checked against each manifest) | Model B, and the Model C `full` profile (Wide ResNet-50-2 weights are 132 MB and its banks 184 MB, above GitHub's 100 MB file limit) |
| The complete classical-baseline artifact (Model A, about 1.5 MB per category) | Per-run example figures (about 6 MB each) |
| `samples/`: 29 VisA test images (2 normal and 2 anomalous per category, plus the featured candle example), the masks of the anomalous ones, `manifest.json` and `ATTRIBUTION.md` (5.5 MB), built by `python scripts/export_samples.py` | |

The export copies files byte for byte, checks the weights against the SHA-256 in the manifests, and refuses to finish unless every copied artifact passes the artifact store's integrity checks (Model C is loaded with the bundled weights) and the copied results pass the dashboard's validation. Resource needs, measured locally on CPU: about 0.2 s per image for Model C, about 0.4 s to load an artifact, and a peak of about 1.1 GB of memory after loading all seven categories one after another (one category at a time needs less). Locally, scores computed from the bundle alone (no `INSPECTAI_*` variables, no weights cache) matched the stored evaluation scores exactly for 28 test images across all seven categories. These checks were made locally. On Streamlit Community Cloud only the visual inspection above has been done; the app's memory use on the host and its behavior under load are unmeasured. The `.streamlit/config.toml` of the repository turns the file watcher off (`fileWatcherType = "none"`), which fixed a `KeyError: 'inspectai.ui'` start-up failure seen on the host.
